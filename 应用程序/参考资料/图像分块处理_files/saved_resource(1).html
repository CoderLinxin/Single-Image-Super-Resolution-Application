一、原理

图像分块处理后再拼接合并的原理是通过将大图分为小块进行处理，节省内存和计算资源，并通过重叠区域避免切块之间的边缘效应。最终，通过合并每个处理过的小块，并对重叠区域进行加权平均，生成处理后的完整图像。

高分辨率图像分块处理后再拼接合并的原理主要包括以下几个步骤：

1.1 图像分块

对于大尺寸图像，直接进行处理（如大模型去噪、超分、滤波、增强等）可能会消耗大量内存和计算资源，显存不足。因此，通常会将图像分成多个小块进行逐块处理，这些小块的大小通常是预设的。

分块处理不仅可以减少内存占用，还能提高并行处理的效率。

在下面代码中，使用了 256x256 大小的块来分割图像，具体的分块方式通过 tile 和 stride（步长）来控制：

tile：每个小块的大小，通常是 256x256 或其他预设大小。 tile_overlap：相邻切块之间的重叠区域的像素，通常是16或32。 stride：每次移动的步长，决定了两个小块之间的重叠区域。通常设定为 tile - tile_overlap，即 224 像素，这样相邻的切块会有一定的重叠部分， 以避免切块间的边缘效应。

对每个 256x256 的小块进行处理，例如应用超分模型或滤波器（如双边滤波、高斯滤波等）。这种操作会在每个小块上独立进行，不会干扰其他小块的处理过程。

1.3重叠区域

为了避免分块处理时产生的拼接接缝（seam），会在每个小块之间设置重叠区域。在本例中，tile_overlap = 32，表示每个相邻切块之间有 32 像素的重叠部分。

这种重叠区域有助于减少处理时出现的边缘效应，特别是在图像平滑和去噪等操作中，保证不同小块之间的过渡更加平滑。

在拼接时，通常会根据权重对重叠部分进行加权平均处理，确保不同块之间的拼接更加自然。

1.4图像合并1.4.1 图像合并过程

分块处理完成后，需要将所有处理过的小块重新拼接成一张完整的图像。

拼接操作通常是根据每个小块的位置信息进行的，将每个小块放回原图的对应位置。

如果存在重叠区域，则使用加权平均等技术来合并重叠区域，以避免拼接线的明显可见性。

在代码中，通过以下方式实现合并：

E[h_idx:h_idx + tile, w_idx:w_idx + tile, :] += out_patch W[h_idx:h_idx + tile, w_idx:w_idx + tile, :] += out_patch_mask
登录后复制

上面代码中变量解析：

变量：E 这是一个与输入图像大小相同的数组，用于存储所有处理后的块（out_patch）的累加值。 每个像素位置的值是该像素被多个块覆盖后的累加结果。 累加块的像素值，用于记录图像内容。 变量：W 权重矩阵，与 E 大小相同，用于记录每个像素被覆盖的次数（即权重）。 每当一个块（out_patch）覆盖到某个像素时，对应位置的 W 加 1（或其他加权值）。 累加权重，用于记录每个像素被覆盖的次数。 变量：out_patch 处理后的单个块的结果。其大小与切块（tile x tile）一致。 变量：out_patch_mask 用于记录当前块的权重，通常是全 1 的数组，与 out_patch 大小相同。
登录后复制1.4.2 累加处理1.4.2.1分块对应到整体图像的位置

h_idx:h_idx + tile 和 w_idx:w_idx + tile 定义了当前块在整幅图像上的位置范围。
比如，如果 h_idx=0, w_idx=0, tile=256，表示将当前块放置在整幅图像的 (0:256, 0:256) 区域。

1.4.2.2 累加处理

E 和 W 分别累加对应的块：

E：累加块的像素值，用于记录图像内容。 W：累加权重，用于记录每个像素被覆盖的次数。
登录后复制1.4.2.3 重叠区域的处理

如果相邻块有重叠部分（如有 32 像素重叠），这些区域会被多个块累加，导致 W 中这些像素的值大于 1。

这种方式为后续的加权平均准备了基础数据。

1.4.3 计算最终结果

通过上面计算得到的 E 和 W 进行加权平均：

output = np.divide(E, W, out=np.zeros_like(E), where=(W != 0)).astype(np.uint8)
登录后复制

上面代码中各个参数的解析见下：

按权重计算加权平均：
对于每个像素，最终的值是所有覆盖该像素的块的累加值（E）除以权重（W）。
加权平均公式为：
output(i,j,k)​=W(i,j,k)​E(i,j,k)​​,ifW(i,j,k)​=0

where=(W != 0) 的作用：
确保只对那些权重不为 0 的像素进行计算。
如果某些像素未被任何块覆盖（W=0），则避免出现除零错误，同时将这些像素值设为零。

out=np.zeros_like(E)：
指定输出数组为与 E 大小相同的零矩阵，确保结果被正确存储。

astype(np.uint8)：
将结果从浮点型转换为无符号 8 位整数（图像常用数据类型），方便后续的显示或保存。

1.4.4 运行逻辑示例

假设输入图像为 512x512，分块大小为 256x256，重叠 32 像素：

（1）处理第一个块：
块位置：(0:256, 0:256)。
E 和 W 中的对应区域更新。

（2）处理第二个块（右侧）：
块位置：(0:256, 224:480)（与第一个块有 32 像素重叠）。
重叠区域的值被累加，权重 W 的对应区域值变为 2。

（3）所有块处理完成后：
E 中每个像素包含了所有覆盖它的块的累加值。
W 中每个像素包含了覆盖它的权重。

（4）生成完整图像：
通过 E / W 计算每个像素的加权平均值，避免拼接接缝。

1.5 最终输出

最终，通过对所有小块的处理结果进行加权平均后，可以得到一张完整的图像。

图像的边缘可能会有轻微的过渡，但由于使用了重叠区域和加权处理，最终拼接后的图像看起来会比较平滑。

二、实例1：色板赋值

结合上面原理，为了更直观的讲清楚分块后拼接的过程，下面我用一段代码演示，此代码主要是对一副全黑的10241280图像，分成256256大小块处理，分别对每一小块随机赋值不同的颜色，这样可以直观的看到分块处理后再拼接合并的结果。

2.1 代码

完整代码见下：

import cv2 import numpy as np # 创建一张纯黑色的图像 h, w = 1024, 1280 # 假设输入图像的大小为 1024x1280 img = np.zeros((h, w, 3), dtype=np.uint8) # 纯黑色图像 (高，宽，通道数) tile = 256 # 每个块的边长是256个像素 tile_overlap = 32 # 相邻切块之间的重叠区域是32像素 window_size = 8 # 确保切块大小是 window_size 的倍数 h, w, c = img.shape # 获取输入图像的高、宽、通道数 tile = min(tile, h, w) # 切块的大小，不能超过图像的高度和宽度 assert tile % window_size == 0, "tile size should be a multiple of window_size" # 确保切块大小是 window_size 的倍数 stride = tile - tile_overlap # 每次切块移动的步长，确保切块间存在重叠区域 256-32 = 224 # 切块会从图像的左上角开始，按步长（224）逐步生成切块的位置 h_idx_list = list(range(0, h - tile, stride)) + [h - tile] # 高度方向的切块索引 w_idx_list = list(range(0, w - tile, stride)) + [w - tile] # 宽度方向的切块索引 # 创建用于存储结果的张量 E = np.zeros((h, w, c), dtype=np.float32) # 存储最终合并结果 E_1 = np.zeros((h, w, c), dtype=np.uint8) # 存储最终分块结果 W = np.zeros_like(E) # 存储权重 # 遍历所有切块 for h_idx in h_idx_list: for w_idx in w_idx_list: # 提取当前切块 in_patch = img[h_idx:h_idx + tile, w_idx:w_idx + tile, :] # (tile, tile, c) # 随机生成一个RGB颜色值 (0-255之间的随机整数) random_color = np.random.randint(0, 256, size=(1, 1, 3), dtype=np.uint8) # 为当前切块分配随机颜色 color_patch = np.full_like(in_patch, random_color, dtype=np.uint8) # 生成与切块输出相同形状的权重 color_patch_mask = np.ones_like(color_patch,dtype = np.float32) # 累加结果到对应位置 E_1[h_idx:h_idx + tile, w_idx:w_idx + tile, :] = color_patch E[h_idx:h_idx + tile, w_idx:w_idx + tile, :] += color_patch W[h_idx:h_idx + tile,w_idx:w_idx + tile,:] += color_patch_mask # 计算最终结果，防止除零 output = np.divide(E,W,out = np.zeros_like(E),where=(W != 0)).astype(np.uint8) cv2.imwrite(r"F:\Code\Python\Result\image_stitching_result\original.bmp",img) cv2.imwrite(r"F:\Code\Python\Result\image_stitching_result\output.bmp",output) cv2.imwrite(r"F:\Code\Python\Result\image_stitching_result\output_1.bmp",E_1) # 显示最终结果 cv2.imshow("output", output) cv2.imshow('input_img',img) cv2.imshow("E_1",E_1) cv2.waitKey(0) cv2.destroyAllWindows()

def test(img_lq, model, args, window_size): # 将模型在分布式或多卡上运行 model = nn.DataParallel(model).to('cuda') # 使用nn.DataParallel分布式 img_lq = img_lq.to('cuda') # 将输入移到GPU上 if args.tile is None: # 如果未指定切块大小，直接对整张图像进行推理 # test the image as a whole output = model(img_lq) # 调用模型处理整个输入图像 else: # test the image tile by tile b, c, h, w = img_lq.size() # 获取输入图像的批次大小、通道数、高度和宽度 tile = min(args.tile, h, w) # 切块的大小，不能超过图像的高度和宽度。 assert tile % window_size == 0, "tile size should be a multiple of window_size" # 确保切块大小是 window_size 的倍数，满足模型的分块要求。 tile_overlap = args.tile_overlap # 相邻切块之间的重叠区域，用于避免拼接时的伪影 sf = args.scale # 缩放因子，用于超分辨率或其他场景 stride = tile - tile_overlap # 每次切块移动的步长，确保切块间存在重叠区域 h_idx_list = list(range(0, h-tile, stride)) + [h-tile] # 分别生成高度和宽度方向的切块起始索引，最后一个索引确保覆盖图像的边缘。 w_idx_list = list(range(0, w-tile, stride)) + [w-tile] # E = torch.zeros(b, c, h*sf, w*sf).type_as(img_lq) # 单卡 E = torch.zeros(b, c, h*sf, w*sf).to(img_lq.device) # 确保张量在 GPU 上 # 存储最终的预测结果，形状为(b, c, h*sf, w*sflike(E)) W = torch.zeros_like(E) # 存储每个像素的权重，用于计算加权平均 for h_idx in h_idx_list: for w_idx in w_idx_list: in_patch = img_lq[..., h_idx:h_idx+tile, w_idx:w_idx+tile] # 提取当前切块，形状为(b,c,tile,tile) out_patch = model(in_patch) # 自动分发到多个GPU # 对当前切块进行模型推理，自动分配到多个 GPU out_patch_mask = torch.ones_like(out_patch) # 生成与输出同形状的权重张量（全为 1），用于计算重叠区域的加权平均 E[..., h_idx*sf:(h_idx+tile)*sf, w_idx*sf:(w_idx+tile)*sf].add_(out_patch) # 将当前切块的预测结果累加到对应的结果张量区域 W[..., h_idx*sf:(h_idx+tile)*sf, w_idx*sf:(w_idx+tile)*sf].add_(out_patch_mask) # 累加权重，记录该区域被处理的次数 output = E.div_(W) # 将累加结果张量 E 除以权重张量 W，完成重叠区域的加权融合 return output
